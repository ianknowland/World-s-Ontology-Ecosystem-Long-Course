# Ontology Tools Used in the Course

## Required / commonly used

- GitHub — repository work, pull requests, peer review, Discussions
- Protégé Desktop — ontology editing
- HermiT or another OWL 2 DL reasoner — classification and consistency checks
- RDF / RDFS / OWL — Semantic Web representation languages
- Markdown — project notes and reflections

## Used in selected modules

- Large language models — controlled support and evaluation target
- SHACL or equivalent explicit constraint validation — Project 4 concepts
- Python / API tooling — optional advanced implementation for Project 4

The point of the course is not tool memorization. Tools are used to make modeling commitments explicit, test consequences, and support review.
