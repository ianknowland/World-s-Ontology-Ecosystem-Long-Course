# Case 4 — Modeling a System

## Scenario

An unmanned sensing system contains a sensor component. The sensor bears a sensing function that is realized in a measurement process. The measurement process produces a measurement datum with a numeric value and unit. A software component receives the datum for display.

## Competency questions

- What components are part of the system?
- What function does the sensor bear?
- In what process is the function realized?
- What datum is generated by the process?
- What value and unit are recorded?
- Which software component receives the datum?

Your model must distinguish the system, its components, functions, processes, data, and literal values.
