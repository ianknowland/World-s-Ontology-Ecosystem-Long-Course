# Case 2 — Modeling the Unreal

## Scenario

A historical-literary database describes a fictional detective, a fictional residence, a published novel, and a real author. The database must answer questions about both the real information artifacts and the fictional entities represented in them without collapsing the two.

## Competency questions

- Which real information artifact describes the fictional detective?
- Who authored that artifact?
- Which fictional residence is represented as the detective’s home?
- What claims belong to the fictional setting rather than to the actual world?

Construct a model that makes the real/fictional and entity/information distinctions explicit. Explain the ontological commitments you adopt rather than relying on labels alone.
