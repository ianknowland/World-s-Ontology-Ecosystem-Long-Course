# The World’s Ontology Ecosystem 

**15-week asynchronous course**  
**Instructors:** John Beverley and Barry Smith

This repository is the semester-course version of **The World’s Ontology Ecosystem**. 

The course treats ontology engineering as a practical discipline. The central theme is that producing ontology syntax is relatively easy; producing ontology content that is clear, reusable, logically sound, standards-aligned, and fit for operational use is much harder.

## Start Here

1. Read [`SETUP.md`](SETUP.md) and fork this repository.
2. Review the [`15-week schedule`](course/schedule.md).
3. Read the [`participation requirements`](course/participation.md).
4. Open the [`weekly module`](weeks/) for the current week.
5. Open the corresponding assignment in [`projects/`](projects/) when a project is due.
6. Submit Projects 1–5 by pull request. Projects 1–4 each require a substantive peer review of another student’s pull request.
7. Complete all five debate reflections in GitHub Discussions.

## Course Architecture

| Weeks | Focus | Graded milestone |
|---|---|---|
| 1–3 | Ontology ecosystem and foundations | Project 1 |
| 4–7 | Ontology tradecraft and careful modeling | Project 2 + PR reviews |
| 8–10 | Ontology and artificial intelligence | Project 3 |
| 11–13 | Ontology-enabled AI workflows and validation | Project 4 |
| 14–15 | Competing visions and synthesis | Project 5 Capstone |

## Assessment

| Weight | Assessment |
|---:|---|
| 30% | Asynchronous Participation: required peer pull-request reviews and five structured debate reflections |
| 30% | Projects 1–4: Pull Request Projects |
| 40% | Project 5: Capstone Synthesis |

See [`course/grading.md`](course/grading.md) for the working rubrics.
